# Security Policy

## Supported versions

Only the latest chart release receives fixes. The chart tracks the latest Mailpit release; vulnerabilities
in Mailpit itself should be reported upstream at https://github.com/axllent/mailpit/security.

## Reporting a vulnerability

Please report vulnerabilities in the chart privately through
[GitHub Security Advisories](https://github.com/rvvg/mailpit-helm/security/advisories/new).
Do not open a public issue. You will get a response within 7 days.
